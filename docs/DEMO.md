# Демонстрация «ПОС»

Сценарий показывает добавление студентов и критериев, выставление оценок,
расчёт итога, экспорт CSV, исправление и отмену, обработку ошибочного ввода.

Команды ниже выполняются из корня проекта. Нужна Go 1.27 или новее.
Ведомость хранится в памяти: каждая новая сессия начинается с пустого курса.

## Интерактивный запуск

```bash
go run -buildvcs=false ./cmd/pos
```

Выберите номер действия и вводите ответы по одному на строку, завершая Enter.
Имена и названия могут содержать пробелы. ID назначаются автоматически;
узнать их можно командами `2` и `4`. Максимум и вес — положительные конечные
числа, балл — от нуля до максимума критерия. Десятичный разделитель — точка.

Ошибка отменяет текущую операцию и возвращает главное меню.
Для повторения нужно заново выбрать действие. `0` завершает программу
в главном меню; внутри вопроса о балле это допустимая нулевая оценка.

## Воспроизводимая демонстрация

```bash
sh scripts/demo.sh
```

В [`session.txt`](demo/session.txt) записаны ответы, включая намеренно
пустое имя для ошибочного ввода. Сохраняйте пустую строку при копировании.
При перенаправлении ввода ответы не дублируются в выводе программы;
их можно сопоставить с вопросами по этому файлу.

[Скрипт](../scripts/demo.sh) создаёт новый каталог `/tmp/pos-demo.XXXXXX`,
подставляет его вместо `@EXPORT_DIR@` и запускает приложение.
В каталоге сохраняются фактический ввод `session.txt`, протокол `console.txt`
и три CSV-файла. В конце скрипт печатает путь каталога и содержимое выгрузок.
Для повторного запуска выбирается новый каталог.

Сценарий выполняет следующие действия:

| Шаг | Ввод в меню | Что показывает |
| --- | --- | --- |
| Пустой курс | `2`, `4`, `11` | Пустые списки; итоговая ведомость требует студентов |
| Неизвестная команда и пустое имя | `99`; `1` с пустой строкой | Ошибки; следующему студенту по-прежнему назначается ID 1 |
| Студенты | `1`, `Анна Иванова`; `1`, `Борис Петров` | Участники с ID 1 и 2 |
| Рубрикатор | `3`, `Проект`, `10`, `1`; `3`, `Экзамен`, `20`, `3` | Критерии с разными максимумами и весами |
| Оценка Анны за проект | `5`, `1`, `1`, `8` | Оценка 8 из 10 |
| Повторная оценка | `5`, `1`, `1`, `9` | Дубликат отклоняется, балл остаётся 8 |
| Неизвестный критерий и превышение максимума | `5`, `1`, `99`, `5`; `5`, `1`, `2`, `21` | Оценки не сохраняются |
| Остальные оценки | Анна: 10/20 за экзамен; Борис: 10/10 и 20/20 | Полная ведомость обоих студентов |
| Итоги и первая выгрузка | `6`, `9`, `11`, `12` с нужными ID/путём | Итоги 5.75 и 10.00; файл `final.csv` |
| Ошибочное исправление | `7`, `1`, `1`, `12` | Ошибка диапазона; итог Анны остаётся 5.75 |
| Исправление | `7`, `1`, `1`, `10`; `9`, `1` | Итог Анны становится 6.25 |
| Отмена | `8`, `1`, `2`; `9`, `1`; `10`, `1` | Окончательный итог недоступен, предварительный равен 2.50 |
| Неполная ведомость | `11`, `12` с новым путём | Файл `incomplete.csv`: у Анны пустой итог, у Бориса 10.00 |
| Существующий файл | `12` с прежним путём `final.csv` | Ошибка; первая выгрузка сохраняется |
| Повторное выставление после отмены | `5`, `1`, `2`, `20`; `9`, `1`; `11`, `12` | Оба итога равны 10.00; файл `updated.csv` |
| Выход | `0` | Завершение с кодом 0 |

## Ожидаемые результаты

Перед первой выгрузкой общая ведомость содержит:

```text
Итоги студентов:
ID=1 | Анна Иванова | итог=5.75 из 10 | оценок: 2/2
ID=2 | Борис Петров | итог=10.00 из 10 | оценок: 2/2
```

Содержимое `final.csv`:

```csv
student_id,student_name,total,graded_count,criterion_count,status
1,Анна Иванова,5.75,2,2,final
2,Борис Петров,10.00,2,2,final
```

Для Анны: `10 × (1 × 8/10 + 3 × 10/20) / (1 + 3) = 5.75`.
После исправления проекта на 10 итог равен 6.25. После отмены экзамена
предварительный итог равен `10 × (1 × 10/10 + 3 × 0/20) / 4 = 2.50`.
Окончательный итог при этом недоступен.

Содержимое `incomplete.csv`:

```csv
student_id,student_name,total,graded_count,criterion_count,status
1,Анна Иванова,,1,2,incomplete
2,Борис Петров,10.00,2,2,final
```

После повторного выставления Анне 20 за экзамен итоговая ведомость содержит
два результата 10.00. Содержимое `updated.csv`:

```csv
student_id,student_name,total,graded_count,criterion_count,status
1,Анна Иванова,10.00,2,2,final
2,Борис Петров,10.00,2,2,final
```

В сценарии ожидаются девять сообщений об ошибках. Они не прерывают сеанс
и не добавляют посторонних студентов, критериев или оценок.
Повторный экспорт в существующий файл не меняет `final.csv`;
выгрузки отражают состояние данных на момент соответствующего экспорта.

## Завершение ввода посреди операции

```bash
go run -buildvcs=false ./cmd/pos < docs/demo/incomplete-student.txt
go run -buildvcs=false ./cmd/pos < docs/demo/incomplete-evaluation.txt
go run -buildvcs=false ./cmd/pos < docs/demo/incomplete-export.txt
```

| Файл | Где обрывается ввод | Ожидаемый результат |
| --- | --- | --- |
| [incomplete-student.txt](demo/incomplete-student.txt) | После выбора добавления студента, до имени | Нет подтверждения добавления студента |
| [incomplete-evaluation.txt](demo/incomplete-evaluation.txt) | После ID студента и критерия, до балла | Студент и критерий созданы, оценка не выставлена |
| [incomplete-export.txt](demo/incomplete-export.txt) | После выбора экспорта, до пути | Оценка выставлена, файл не создаётся |

Все три запуска завершаются с кодом 0 без сообщения об ошибке.
Незавершённая операция не подтверждается и не сохраняется.

Сквозная цепочка с чтением CSV проверяется
в [internal/bootstrap/export_test.go](../internal/bootstrap/export_test.go).
Ошибки потоков консоли и обрывы форм проверяются
в [internal/adapters/cli](../internal/adapters/cli).
